# 0.1.1

Maintenance release — store-readiness and a small robustness fix.

## Changes

- Raise `minAppVersion` to `1.7.2`, which `Workspace.revealLeaf` requires. This clears the community-store lint error (`no-unsupported-api`) so the plugin is submission-ready.
- Rename command ids to drop the redundant plugin-id prefix, per the Obsidian command-id convention (`open-migrator`, `revert-last-migration`).
- Scan reports now pick a non-colliding filename if two are written within the same second, instead of failing to write the second one.
